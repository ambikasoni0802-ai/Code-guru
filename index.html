🐙 GitHub par push karein

Apna GitHub Personal Access Token (Settings → Developer settings → Tokens) yahan daalein. Ye sirf aapke browser mein save hota hai, kahin bhi bheja nahi jaata (sirf GitHub ko).

▲ Netlify par live deploy karein

Apna Netlify Personal Access Token (User settings → Applications → New access token) daalein. Site ID khaali chodenge to nayi site ban jayegi.

🗄️ Apna Database Jodein (Supabase — free)

supabase.com par free account banayein, apna Project URL aur "anon public" key yahan daalein. Table pehle Supabase dashboard se banani hogi.

Naya row jodne ke liye JSON likhein, jaise: {"name":"Test","value":"123"}

📱 Apni website ko Android App banayein

Ye website ek PWA hai, isliye PWABuilder (Microsoft ka free, official tool) se asli installable .apk file ban sakti hai — bina Android Studio seekhe. Apni (ya kisi bhi) live website ka link daalein.

Waha jaakar: 1) URL check hoga → 2) "Package for Stores" → 3) "Android" choose karein → 4) Download button se apni .apk file mil jayegi. Wahi file phone mein install ho jayegi ya Play Store par bhi daal sakte hain.

🧩 Naya app blocks se banana ho (bina coding)

Agar coding ke bina, drag-drop se ek alag Android app banana hai (jaise game ya calculator), to MIT App Inventor bhi ek accha, bilkul free, beginner-friendly tool hai.

🔑 Apni Code Guru API Key banayein

Ye key bana lene ke baad, aap seedha Code Guru ke API se apne kisi bhi app/website mein AI jawab mangwa sakte hain — Groq par jaake alag se account banane ki zaroorat nahi.
